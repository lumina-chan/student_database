# Student Database

A simple command-line student database built with Python.

## Version 1

This is the first version of the project.

It currently supports:

- Adding students
- Searching students by name
- Displaying all students
- Basic input validation
- Exiting the program

Student records are stored in memory and are not persistent between program runs.

## What's Next?

The project will evolve into a more complete academic record manager with:

- Persistent CSV storage
- Full CRUD operations
- Search by ID and name
- Sorting
- Dynamic student attributes
- Stronger validation and error handling
- Improved terminal interface

More features will be added as the project develops.
